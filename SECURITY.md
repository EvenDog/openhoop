# Security policy

## Supported versions

Only the [latest release](https://github.com/EvenDog/openhoop/releases/latest) gets security fixes. OpenHoop updates itself, so a fix reaches everyone through the next version.

## Reporting a problem

Please don't report security problems in a public issue. Use [Report a vulnerability](https://github.com/EvenDog/openhoop/security/advisories/new) on the Security tab instead; only the maintainer can see what you send.

Helpful things to include:

- what the problem is and what someone could do with it
- the steps to make it happen, and a sample file if it's set off by opening one (an embroidery file, a design, an SVG or an image)
- the OpenHoop and macOS versions you used

## What happens next

OpenHoop is made by one person in their spare time, so there's no promised reply time, but reports are read and answered. Once a fix is out, the report can be made public, with credit to you if you'd like it.
